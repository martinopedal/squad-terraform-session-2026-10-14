Short session map for Haflidi

This page tracks the current public docs. It keeps the flow short. It keeps the ownership clear.

It is built for screen use on GitHub Pages. The full timed script stays in the talk track.

Flow in 5 steps

  1. Clean start on the demo VM

    Haflidi runs C0 on the clean Windows 11 VM. He shows install, login, copilot, and squad init. Martin frames the boundary and moves the session from setup into the prepared presenter flow.

  2. CLI and Squad working model

    Martin walks the CLI surface and the three Terraform lanes. Haflidi explains Squad as the coordination layer with routing, handoffs, decisions, and one owner per shared surface.

  3. Qualified module and review gates

    Martin introduces the inherited public module revision and the consumer view. Haflidi explains the module boundary, caller-owned provider and state, and the gate flow around pull requests, review, environment approval, OIDC, and runtime checks. The logged eval result is B1v2 5/5, B2 5/5, and B3 4/5.

  4. Guidance, source checks, and repair loop

    Martin shows agents, skills, MCP source lookups, and permissions. Haflidi explains the difference between instructions, skills, and MCP, plus the validator and reviewer boundaries through the mutation and repair loop.

  5. Online consumer view and close

    Martin shows the Online consumer page and the gated delivery path. Haflidi maps that result back to the same gate flow and closes the loop on what the audience should take away.
