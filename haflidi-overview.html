A. What is this?

We present a 60-minute session on Squad and GitHub Copilot CLI used to build, review, and ship Terraform.

The main story is the working method: agents, prompts, PRs, GHAS, review, gates, and checks.

The deployed AKS Automatic cluster is the outcome and an added benefit. It serves the page AKS Automatic | NIC 2026 demo.

How we got to a secure, well-aligned cluster

  1. 1. Start with a private-by-default Terraform contract

    We keep the module boundary clear. The caller owns providers, backend, and environment values.

  2. 2. Add tests and keep the same gates

    We make the change reviewable. We prove the contract with tests before anything moves forward.

  3. 3. Use GitHub controls

    We use pull requests, GHAS, required review, and protected main.

  4. 4. Deploy through OIDC and an approved pipeline

    The consumer repo shows the gated path. The deployment comes from reviewed GitHub workflow runs, not from a laptop.

  5. 5. Finish with runtime checks

    The result is the cluster and page. The final runtime evidence is 29/29 checks.
