# Presentation design context

Deck maintainers and design checks use this file to preserve the approved conference composition. It records existing decisions, not a new brand proposal.

## Register

brand

## Users

Infrastructure engineers watch a projected 16:9 screen in Room 6. Martin Opedal, Enterprise Cloud Solution Architect, Microsoft, and Haflidi Fridthjofsson, Sr Cloud Solution Architect, Microsoft, deliver the session together using a separate speaker window and silent local clips. The operator needs predictable controls without internet access.

## Product purpose

Teach useful Copilot CLI and Squad workflows through a reusable Terraform module and a private Azure landing-zone consumer. A polished deck must distinguish source facts, intended demonstrations, actual evidence, and unresolved environment gates.

## Voice and identity

Direct, readable, evidence-led. Preserve the official NIC 2026 system now implemented in `src\theme.css`: cyan and ink surfaces, embedded Roboto typography, NIC26 logos, and no Fluent accent palette. Code uses a single monospace stack.

## Anti-references

No generic command catalog, repeated decorative card grid, remote fonts, gradients, dashboard decoration, fake terminal output, success-shaped recording placeholders, or Fluent-blue carryover. No PowerPoint or print layout.

## Design principles

- One message per slide, with varied layouts chosen for the content.
- Product-layer labels clarify responsibility instead of relying on color alone.
- Diagrams explain ownership and dependencies; they do not claim deployment.
- Pending footage stays explicit and supports the same useful spoken explanation.

## Accessibility and delivery

Normal text needs 4.5:1 contrast and large text 3:1. Preserve keyboard access, visible focus, reduced motion, descriptive graphics, native media controls, and complete spoken notes. Test every slide and fragment at 1280 x 720 and 1920 x 1080, then inspect the captures. Keep one pre-show opening page, 25 timed main slides, six optional references, and the 26/27/7-minute delivery contract.
